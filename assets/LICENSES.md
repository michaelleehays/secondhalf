The packs themselves are not in the repo: `fetch_makehuman.sh` downloads them into the gitignored
`vendor/makehuman/`. Each pack's metadata (`vendor/makehuman/packs/*.json`) lists every asset as CC0.

Tools (not shipped): Blender as the `bpy` Python package (GPL), MPFB 2 (GPL). Using GPL tools
does not put their licence on the models they make.
